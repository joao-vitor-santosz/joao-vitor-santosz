## 👨‍💻 Quem sou?

Sou estudante de **Engenharia de Software** e desenvolvedor em formação, apaixonado por tecnologia, resolução de problemas e criação de soluções digitais.

Minha jornada na programação vai além de aprender linguagens e frameworks. Busco entender como cada parte de uma aplicação funciona, desde a interface que o usuário utiliza até as regras de negócio, APIs e bancos de dados que fazem tudo funcionar.

Atualmente, estou aprofundando meus conhecimentos em desenvolvimento Full Stack, construindo projetos práticos e evoluindo minha capacidade de transformar ideias em aplicações reais.

Acredito que um bom desenvolvedor não é aquele que sabe todas as respostas, mas aquele que sabe investigar problemas, aprender continuamente e encontrar soluções consistentes.

> 💡 **Meu objetivo:** evoluir como desenvolvedor, construir produtos úteis e contribuir para projetos que gerem valor de verdade.

## 🛠️ Como faço?

Para mim, desenvolver software é um processo de investigação, construção e melhoria contínua.

- 🔍 **Entendo o problema:** procuro compreender os requisitos antes de sair escrevendo código.
- 🧩 **Divido para conquistar:** organizo funcionalidades em partes menores para facilitar o desenvolvimento e a manutenção.
- 🏗️ **Busco boas práticas:** estudo organização de código, separação de responsabilidades e estruturas que facilitem a evolução das aplicações.
- 🧪 **Aprendo na prática:** transformo conceitos estudados em projetos e experimentos reais.
- 🔄 **Evoluo continuamente:** revisito implementações, investigo erros e procuro entender não apenas como resolver um problema, mas por que a solução funciona.
- 🤝 **Compartilho minha jornada:** utilizo o GitHub para documentar meu aprendizado, versionar projetos e acompanhar minha evolução.

Acredito que escrever código é importante. **Entender as decisões por trás dele é o que me permite evoluir como desenvolvedor.**

## 🚀 Qual impacto quero gerar?

Quero desenvolver soluções que tornem processos mais simples, experiências digitais mais agradáveis e problemas complexos mais fáceis de resolver.

Meu foco é construir aplicações que combinem:

- **Utilidade:** resolver problemas reais.
- **Usabilidade:** proporcionar experiências claras e intuitivas.
- **Qualidade:** buscar código organizado e de fácil manutenção.
- **Evolução:** permitir que as soluções cresçam conforme novas necessidades surgem.

Meu objetivo profissional é contribuir com equipes e projetos que valorizem tecnologia, colaboração e aprendizado contínuo, evoluindo para atuar em projetos cada vez mais desafiadores, inclusive no mercado internacional.
